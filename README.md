# Shadow FPV Technology

Local frontend built with React, Vite, GSAP ScrollTrigger, and Three.js.

## Run

npm install
npm run dev

## Production build

npm run build
npm run preview

## Scope

Responsive landing page, procedural interactive circuit board, hardware filters and product dialogs, roadmap, and a local-only interest form. Product visuals are concepts. No pricing, specifications, commerce, or live signup service is implied. The form saves an email only in browser localStorage.

Primary color: purple. Motion respects reduced-motion preferences. The 3D illustration has a fallback when WebGL is unavailable.

The assets/OpenDrone-Web_original folder is a user-supplied reference and excluded from this repository. Local fonts were copied from that MIT-licensed reference; its license is retained at public/reference-license.txt.
